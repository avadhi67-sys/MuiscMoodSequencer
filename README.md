🎵 Overview

SonicFlow is a web-based Music Mood Sequencer. It is designed to
combine music playback, song and artist management, a personal library,
search, authentication, and mood-based sequencing in one application.

✨ Features

🎧 Music player and playback controls

🎭 Mood-based music sequencing

🎵 Add and manage songs

🎤 Add and manage artists

📚 Music library

🔎 Search functionality

🔐 Login and signup

💾 Local/browser storage

🎨 Theme management

🚀 How to Run

Open the SonicFlow folder in VS Code.

Open index.html.

Run the project using a local server such as VS Code Live
Server.

Explore the music library, search, player, and mood sequencer.

🎯 Project Goal

The goal of SonicFlow is to create an interactive music experience where
users can organize music, listen to songs, and build sequences based on
their mood.
